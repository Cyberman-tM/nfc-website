# Entwürfe neuer Datensteine

Hier können vorbereitete Datenstein-Ordner liegen. Für einen neuen Datenstein kopiere den gesamten Inhalt aus `templates/Datenstein/` in einen Unterordner mit der Dn-ID, zum Beispiel `data/drafts/DnF03/`.

Der Entwurfsordner hält den vorbereiteten Datenbankeintrag, NFCTools-Export und Mediendateien zusammen. Er wird nicht von der Website veröffentlicht oder automatisch eingelesen. Wenn der Entwurf fertig ist, kann er in die endgültigen Ablagen (`data/database.json`, `data/nfctools/` und `3d/<Dn-ID>/`) übernommen werden.
