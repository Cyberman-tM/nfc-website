# DnF02 – 3D-Dateien

Hier liegen die STL-Eingabedateien und erzeugten Ansichten für DnF02 im Design-Unterordner `Design01`. `tools/build_models.py` findet Designordner automatisch, sobald mindestens eine STL-Datei darin liegt.

Das Blender-Script erzeugt in diesem Ordner:

- `DnF02.glb`
- `DnF02_vorne.webp`
- `DnF02_hinten.webp`

Die Ausgabe innerhalb jedes Designordners ist nach der unveränderlichen Datenstein-ID benannt. Die Varianten werden in `content/database.json` gepflegt. STL-Dateien und Blender-Script werden nicht auf der Website angezeigt.
